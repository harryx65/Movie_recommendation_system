# 🎬 Movie Recommender System

A Machine Learning based Movie Recommender Web App built using **Streamlit**.  
It recommends similar movies based on cosine similarity and displays movie posters using **TMDB API**.

---

## 🚀 Demo

This app suggests 5 similar movies based on the movie you like.

---

## 📌 Features

- Movie recommendation using ML similarity model
- Displays movie posters dynamically from TMDB API
- Interactive Streamlit web interface
- Fast and lightweight
- Simple and clean UI

---

## 🧠 How It Works

The system uses **content-based filtering**:

1. Movies are converted into vectors using NLP/feature engineering
2. Cosine similarity is calculated between movies
3. When a user selects a movie, top 5 similar movies are recommended
4. Posters are fetched from TMDB API
